4Stockfish

A Melee combo advisor. Pause a match, search ahead through real game simulations, and see what you could have done.

View on GitHub

How it works

Press Start in a match to freeze the game and search many input trees for the next few dozen frames. Results are listed by damage or KO. Filter by move, sort by length, and preview a line with A.

Controls

Start (in game)Begin or end search
APreview the selected combo
XToggle sort (damage / length)
Stick up / downScroll results
Stick left / rightMove filter
D-pad left / rightSearch window (restarts)
L / RAllowed endlag between hits (restarts)

Status

  • Opponent DI and teching are not in the search yet.
  • Best tested so far on a few characters (Marth, Fox) vs CPUs.
  • In-game Start only for now — Slippi / analyze-mode is planned.

Built on

4Stockfish runs on the melee-pc native port of Super Smash Bros. Melee (from the decompilation). Bring your own NTSC-U 1.02 disc image. Full port docs live upstream.
